# zapret2-windows

Готовый комплект **zapret2 для Windows 10 x64 (1803+) и Windows 11 x64**. В архиве уже есть `winws2.exe`, Cygwin DLL и WinDivert. Отдельно устанавливать Cygwin, Python или Windows Terminal не нужно.

Проект использует пользовательский список доменов и набор стратегий для YouTube, Discord и других адресов из списка. Результат зависит от сети и провайдера: проверяйте нужные приложения после выбора стратегии.

> [!IMPORTANT]
> Скачивайте архив со [страницы релизов этого репозитория](https://github.com/lenorio/zapret2-windows/releases). `service.bat` устанавливает **задачу планировщика Windows**, а не службу из `services.msc`. DNS, DoH, маршруты, прокси и `hosts` скрипты не меняют.

## ⚙️ Быстрый старт

1. Скачайте `zapret2-windows-*.zip` из [последнего релиза](https://github.com/lenorio/zapret2-windows/releases/latest) и распакуйте его в папку, например `C:\zapret2`.
2. Запустите [`service.bat`](service.bat). Подтвердите запрос администратора: права нужны для WinDivert и управления задачей автозапуска.
3. Выберите **6. Test all strategies**, чтобы проверить варианты из [`strategies/catalog.json`](strategies/catalog.json) по адресам из [`strategies/targets.txt`](strategies/targets.txt). Тест покажет лучшую стратегию, но не применит её.
4. Выберите **8. Select strategy** и введите ID нужного варианта. Проверьте видео YouTube, Discord и другие нужные сайты вручную.
5. Если нужен автозапуск после перезагрузки, выберите **1. Install autostart**. Без этого шага автозапуск не создаётся.

Для быстрой ручной проверки можно запустить любой `.bat` из [`strategies/`](strategies/) от имени администратора. Он держит `winws2.exe` в видимой консоли до `Ctrl+C` и не создаёт автозапуск. Если обход уже работает, второй процесс не запустится.

## 🧪 Подбор стратегий

В каталоге **26 вариантов**: 22 адаптации стратегий Flowseal, три базовых профиля и `current-custom.bat` — снимок исходной рабочей конфигурации из `C:\zapret2\runtime\active.conf`. В `service.bat` над меню показана выбранная стратегия; пункт **7** выводит полный список.

Тест читает строки вида `Name = "https://host"` и `Name = "PING:1.2.3.4"` из `strategies/targets.txt`. Для URL он проверяет HTTP, TLS 1.2 и TLS 1.3; ping показывает отдельно. Ответы в консоли выделяются цветом. Отчёт сохраняется в `strategies/test results/test_results_YYYY-MM-DD_HH-mm-ss.txt` и содержит результаты по каждому варианту, итоговую таблицу и рекомендацию. Ping служит диагностикой и не влияет на выбор лучшего варианта.

Во время теста текущий `winws2.exe` временно останавливается. После проверки исходная задача или процесс запускается с прежней конфигурацией. Выбранная стратегия и `active.conf` тестом не меняются. Перебор всех 26 вариантов и целей может занять несколько минут; на это время обход будет переключаться между профилями.

Стратегии Flowseal рассчитаны на zapret1 (`winws.exe`). Здесь портированы их TLS-приёмы для zapret2 (`winws2.exe`); параметры запущены через другой движок и не обещают побитно одинакового поведения. Общие профили HTTP, QUIC и Minecraft основаны на локальной конфигурации этого проекта. [Подробнее о переносе](strategies/README.md).

## ℹ️ Частые вопросы

### Как проверить, запущен ли обход?

Откройте `service.bat` → **5. Check status**. Меню выводит `Bypass (winws2.exe) is RUNNING.` или `Bypass (winws2.exe) is NOT RUNNING.`, а также выбранную стратегию и состояние задачи автозапуска.

### Почему ручной `.bat` не запускает второй процесс?

Одновременная работа двух экземпляров `winws2.exe` создаёт конфликт перехвата трафика. Остановите первый через его консоль или исходное меню, затем откройте другой вариант.

### Тест показал лучший вариант, но сайт всё равно не работает

HTTP/TLS-проверка оценивает соединение с указанными адресами. Она не проверяет воспроизведение видео, голосовой канал Discord или вход в игру. Добавьте нужные адреса в `strategies/targets.txt`, повторите тест и проверьте приложение вручную.

### Как остановить обход и убрать автозапуск?

В `service.bat` пункт **3. Stop** останавливает задачу, пункт **4. Remove autostart** удаляет её. Ручной запуск останавливается `Ctrl+C` в своей консоли.

### Что делать, если `winws2.exe` не запускается?

Убедитесь, что распакован весь архив, файлы `bin/cygwin1.dll`, `bin/WinDivert.dll` и `bin/WinDivert64.sys` находятся рядом с `bin/winws2.exe`, а запуск выполнен с правами администратора. Пункт **9. Check files and exclusions** проверяет состав комплекта. WinDivert как драйвер перехвата трафика может быть помещён антивирусом в карантин; проверьте его журнал, если файл исчез.

## 📝 Списки и исключения

Основной список — [`lists/list-all-safe.txt`](lists/list-all-safe.txt), исключения — [`lists/list-exclude-safe.txt`](lists/list-exclude-safe.txt), отдельные YouTube-адреса — [`lists/list-youtube.txt`](lists/list-youtube.txt). В исключениях сохранены домены OpenAI/ChatGPT, чтобы обход не затрагивал соединение Codex. После изменения списков перезапустите действующую стратегию. Перед правкой сохраните копию своих файлов.
