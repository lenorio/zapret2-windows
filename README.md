# Zapret2 Windows

Готовый комплект для Windows 10 x64 (1803+) и Windows 11 x64. Распакуйте архив и откройте `service.bat`. Установка Cygwin, Python или Windows Terminal не нужна: необходимые DLL, драйвер WinDivert и `winws2.exe` находятся в `bin/`. Меню использует встроенную Windows PowerShell 5.1; Windows Terminal используется только если он уже установлен.

## Запуск

1. Распакуйте архив в папку с правом записи, например `C:\zapret2-windows`.
2. Откройте `service.bat` и подтвердите запрос администратора.
3. Пункт **1** устанавливает задачу автозапуска `Zapret2-Windows` и включает обход. Пункты **2–4** запускают, останавливают или удаляют эту задачу.
4. Пункт **5** показывает `Bypass (winws2.exe) is RUNNING.` либо `Bypass (winws2.exe) is NOT RUNNING.`

Установка автозапуска не требуется для ручного запуска. В папке [`strateries/`](strateries/) есть 22 `.bat` файла с названиями вариантов Flowseal. Откройте один из них от имени администратора: `winws2.exe` работает в видимой консоли до `Ctrl+C`. Если `winws2.exe` уже запущен, ручной запуск откажется создавать второй процесс. Сначала остановите текущий обход через то меню, которым он был запущен. Ручные `.bat` не создают задачу автозапуска.

## Стратегии и списки

`strateries/catalog.json` содержит портированные TLS-приёмы из 22 вариантов `general*.bat` проекта Flowseal. Это адаптация для zapret2, а не запуск исходных команд `winws.exe`: фильтрация и параметры у двух версий различаются. Общие профили HTTP, QUIC и Minecraft взяты из проверенной локальной конфигурации zapret2. Подробности и ограничения — в [`strateries/README.md`](strateries/README.md). Ручные варианты доступны для самостоятельного подбора; они не заменяют автоматически активную задачу.

Пункт меню **6** проверяет три базовые TLS-стратегии YouTube и после теста восстанавливает исходную задачу, если она работала. Пункт **8** применяет выбранную базовую стратегию. Проверка URL даёт предварительный результат; после смены стратегии проверьте воспроизведение видео, Discord и новый чат Codex вручную.

В `lists/list-all-safe.txt` лежит пользовательский самосборный список. `lists/list-exclude-safe.txt` исключает домены OpenAI/ChatGPT и другие сохранённые исключения. Меню не меняет DNS, DoH, маршруты, прокси, системный `hosts` или сетевые службы Windows.

## Файлы и лицензии

`bin/`, `lua/`, `data/`, `lists/` и `config/` нужны для работы. `runtime/` создаётся после запуска и не входит в релиз. Дополнительные библиотеки устанавливать не нужно, но **не удаляйте** `cygwin1.dll`, `WinDivert.dll` и `WinDivert64.sys` из `bin/`.

Собственные скрипты и самосборный список распространяются по MIT. Лицензии, происхождение и исходные архивы сторонних компонентов указаны в [`THIRD_PARTY.md`](THIRD_PARTY.md). Основные проекты: [zapret2](https://github.com/bol-van/zapret2), [Flowseal](https://github.com/Flowseal/zapret-discord-youtube), [WinDivert](https://github.com/basil00/WinDivert) и [Cygwin](https://cygwin.com/).
